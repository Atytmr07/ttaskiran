# TT Design — ttaskiran.com

A 100x rebuild of the TT Aşkıran (TT Design) website: a B2B proof-of-craft
instrument for a premium hotel, villa, business-center and residential
renovation contractor in Muratpaşa, Antalya.

Art direction: **Architectural Dossier — Layered Frame Collage** (client-approved
"go.arch" / "The ROOM" references) applied to real business content.

## Stack

- **Next.js 14** (App Router) + TypeScript
- **Tailwind CSS** — design tokens in [`tailwind.config.ts`](tailwind.config.ts)
- **Framer Motion** — micro-animations (respects `prefers-reduced-motion`)
- **next-intl** — native locale routing (`/tr` default, `/en`)
- **lucide-react** — UI icons (brand glyphs are hand-owned in `components/Icons.tsx`)

## Commands

```bash
npm install
npm run dev      # http://localhost:3000  → redirects to /tr
npm run build    # production build (prerenders /tr and /en)
npm start        # serve the production build
```

## Project structure

```
app/[locale]/layout.tsx   Root layout: fonts, i18n provider, viewport frame, side rail, WhatsApp float, SEO metadata
app/[locale]/page.tsx     Home: assembles all sections + LocalBusiness/GeneralContractor JSON-LD
app/[locale]/iletisim/    Dedicated contact page (localized URL: /tr/iletisim ↔ /en/contact) with email form + breadcrumb JSON-LD
app/sitemap.ts            Per-locale sitemap   app/robots.ts  robots policy
components/                14 section + primitive components (Hero, TrustMetrics, ServiceCategories, …)
i18n/                      next-intl routing, request config, locale-aware navigation
messages/{tr,en}.json      All copy — real business content, fully bilingual
lib/site.ts                Non-translatable real data (phone, address, social, links, image paths)
public/images/             Placeholder architectural backdrops (see below)
scripts/gen-placeholders.mjs  Regenerates the placeholder SVGs
```

## ⚠️ Replacing the placeholder imagery

`public/images/*.svg` are **light, abstract placeholders** generated by
`scripts/gen-placeholders.mjs` so the project builds before real photography
exists. They are intentionally not fabricated interiors.

To go live, drop real project photos into `public/images/` and update the paths
in [`lib/site.ts`](lib/site.ts) (`CATEGORY_IMAGES`, `BEFORE_AFTER_IMAGES`). JPG/WebP
work with no further config change. The four category keys (`hotel`, `villa`,
`business`, `residence`) are business-validated — do not rename them.

The **client-logo grid** (`components/ClientLogos.tsx`) uses neutral abstract
marks on purpose — **never imply a named client relationship** until TT Design
supplies verified partner logos.

## i18n

Turkish is the default locale. Copy lives in `messages/tr.json` / `messages/en.json`
with a parallel key structure; components read it via `useTranslations`. The
locale switch preserves the current route.
